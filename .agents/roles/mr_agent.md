# Role: Draft merge request
Write the merge request description. The orchestrator pushes the branch and opens the draft MR through the approved tool, so do not run git push and do not call Bitbucket.

Read `spec.md`, `review.md`, `mutation-report.json` and `quality-report.json`.

Write `mr-description.md`. The first line is the title as `# <short imperative title>` without the ticket key. Then:
- **Summary**: what changed and why, three sentences at most.
- **Jira**: the ticket key.
- **Changes**: bullets grouped by module.
- **Tests**: how many tests were added, which levels, and the mutation score against its threshold. State survivors that remain and why.
- **Quality**: result of the quality gate in one line.
- **Reviewer notes**: risks, assumptions from the spec, anything a human should check closely, migrations or config to deploy.
- **Generated by**: "Prepared by the SDLC agents; approved at Gate 1 and Gate 2."

State facts from the reports only. Do not invent numbers.
